Need a drive-wide file list?

Chrome may block selecting C:\ or system folders. Agentaus cannot override browser or Windows permissions. Choose a specific folder for reading/editing, or import a metadata-only file list.

  1. Download the PowerShell helper and run it on your PC using your normal PowerShell permissions.
  2. Choose a drive/folder. The helper lists names, paths, sizes and dates, skips protected/system locations, and saves a JSON index.
  3. Import that JSON here. Chat can search the index, but cannot read the listed files until you select those files or their folder.
